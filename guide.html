CHATNOTE / GUIDE

从第一个问题开始。

准备一个可用的模型 API 账号，再用一段不含敏感信息的内容开始体验。

01

下载与安装

选择安装版，确认来源与 SHA-256。缺少 WebView2 时从微软官方页面安装运行时；保留已有工作区，不用示例数据覆盖自己的内容。

02

连接你的模型

进入设置 → 模型与连接，添加服务商、API 地址、密钥与模型。密钥保存在系统凭据库。连接检查不会自动发送推理请求；余额不可用时请到服务商官方用量页面查看。

03

提出主线问题

输入一个学习主题并发送。主线默认携带当前主线历史，不包含追问；实际发送范围仍受上下文预算与服务商限制影响。

04

选中原文，继续追问

选中回答中的文字或公式，建立旁支。追问默认使用截至来源回答的快照与本条追问历史，不带兄弟追问、后续主线或私人笔记。

05

需要时选择上下文

主动点击“预览上下文”选择本次范围。主线与追问分别记住选择；新历史不会自动加入已选范围。可恢复默认，再在回答旁查看实际请求内容。

06

导出成果，备份工作区

写私人笔记并导出笔记或导图 HTML。模型整理出来的笔记需在关闭前导出。完整工作区备份用于恢复原会话，不等同于学习成果导出；备份不含系统密钥。

开始前，可能想知道

可以免费使用吗？

当前客户端免费提供测试使用。模型 API 的额度、计费与使用条件由你选择的服务商决定；下载客户端不附赠模型额度。

每个模型都支持图片、文件和语音吗？

不一定。图片取决于所选模型的视觉能力；文件上传成功不代表模型能阅读文件，DeepSeek 原始文档附件尚不能保证直接使用。语音需在模型与连接中选择支持转写的 API 连接；不承诺任意聊天 API 都支持语音。

上下文预算是什么？

它限制本次请求可以携带的历史字符规模，不是服务商余额，也不是精确 token 额度。超出预算时会缩略或省略部分历史；可查看实际请求收据。

删除后能恢复吗？

整个对话进入回收站后保留 24 小时。超时后在下次启动时清理；清理前可恢复，也可确认后立即删除。单条回答删除不进入对话回收站。

我的内容会被上传吗？

本机保存不代表请求完全离线。发送问题时，所选上下文、附件或转写音频会传到你配置的服务。第三方的数据处理规则请查看其政策。

能用 ChatGPT 套餐或在其他平台安装吗？

首期公开试用指南以自备 API 为主，不承诺 ChatGPT 套餐授权与第三方分发的可用性。当前只提供 Windows x64，其他平台尚未交付。

下载慢或者失败怎么办？

下载由 GitHub Releases 提供，速度取决于网络。可打开发布页重试，校验完整文件后再运行。请反馈系统、网络类型和错误时间，不发送密钥或私人聊天。
