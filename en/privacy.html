ChatNote / PRIVACY

Privacy policy

Effective October 17, 2026. This notice separately describes website visits and the ChatNote application. It covers implemented data flows, without promising encryption, sync, or third-party deletion capabilities that are not available.

01

Website hosting and visits

GitHub Pages hosts this website; GitHub Releases distributes installers. GitHub records visitor IP addresses for security, including for signed-out visitors; its logging, retention and processing follow GitHub’s privacy policy. The application checks a public version file and downloads signed updates from GitHub. Hosting providers receive ordinary network information such as IP addresses, without chats, notes or credentials.

02

Website analytics

This website uses Cloudflare Web Analytics to understand page views, referral sources, device categories and page performance. The developer views statistics in the authenticated dashboard; no counters appear on the website. The production website loads Cloudflare’s analytics script and sends visit and performance data to Cloudflare. It uses no analytics cookies and collects no chats, notes, API keys or application usage records. Local previews do not enable analytics. This website also respects browser Do Not Track and Global Privacy Control signals. Network restrictions and blockers can cause undercounting. Installer download figures use GitHub’s public release asset counters; they do not represent unique users or successful installations.

03

Website preferences

Language is selected through page URLs. Selections in interface illustrations stay only in the current page. There are no accounts, and the website collects no chats or API keys. Copy buttons write only the public text you deliberately select to the clipboard.

04

Local client storage

Conversations, revisions, annotation anchors, notes, drafts, reading positions and preferences are saved in your local workspace. Attachments are also stored locally. No developer-hosted cloud sync is offered, and database encryption is not promised. Protect your device and backups. Before converting the database, 0.15.0 keeps chatnote.pre-v015.sqlite beside it. This independent pre-upgrade backup can contain older records and is not rewritten by recycle-bin cleanup. Manage it separately.

05

Credentials and model requests

API keys and login credentials are stored in the system vault. Sending transmits selected context and applicable attachments to your configured model service; transcription sends recorded audio to your selected transcription service. Private notes are not automatically included.

06

Third-party services

Model, transcription, authentication, usage pages and download hosting are third-party services that may process content, accounts and network data. Their own policies and terms apply. ChatNote cannot promise their non-retention or deletion.

07

Retention and deletion

Whole conversations remain in the recycle bin for 24 hours, then are cleared on the next launch after expiry. Restore before cleanup or confirm permanent deletion. Cleanup covers related recovery records and unshared attachments. It does not promise secure disk erasure; exported files and third-party copies need separate management.

08

Exports, backups and feedback

You manage your backups and exports, which may contain private content but do not contain system-vault keys. Contact details, descriptions and screenshots you send to the developer are used for communication and feedback handling. Do not send secrets or sensitive original content; contact the developer to request deletion of submitted feedback.

09

Choices and contact

Choose services, preview context, stop requests, manage the recycle bin and back up. Stopping locally does not retract data already received by a third party. For privacy questions, contact 529023573@qq.com or Xiaohongshu ID 1006863642. Updates to this policy will show their date.
