CHATNOTE / TESTING

Complete a learning session together

The initial beta aims to collect feedback from about 10–20 Windows users. This page is a voluntary testing and contact guide; it does not automatically invite or message anyone.

  1. Record Windows version, network type and client version; verify the downloaded file checksum.
  2. Install on a fresh computer or with a backed-up workspace. Check startup and preservation of existing data.
  3. Configure a working API of your own. Complete a main question and source follow-up without sensitive content.
  4. Choose context deliberately; check that the scope persists through sending, switching and restarting.
  5. Export notes and an HTML map, then restart to check retained conversations and private notes.
  6. Visit and download over both Wi-Fi and mobile data. Record failure times and messages.

Feedback format

Version / Windows version / network type / reproduction steps / expected result / actual result / sanitized screenshot. Do not send API keys, complete private workspaces or sensitive information.

Testers must complete these steps in practice. Automated checks and synthetic demonstrations do not replace real-account, device or regional network validation.
