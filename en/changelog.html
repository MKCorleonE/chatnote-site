Changelog

Client versions and website distribution are tracked separately. Public distribution copies existing installers byte for byte; the website launch does not rebuild them.

01

0.12.0 · Current

Sending no longer forces context preview; deliberate selections remain saved. Fixes startup language flashes and adds a three-language privacy policy, a 24-hour recycle bin, a laboratory placeholder and a participation page.

02

0.11.0 · Rollback

Improves reading markers during scrolling, pasted-image previews and context-window layout. Moves voice settings to Models & connection and fixes repeated spring expansion in mind maps.

03

Website launch · 2026-10-13

An independent public website, three-language guides, a synthetic interface walkthrough and interactive mind map. Installers are mirrored to independent public Releases while application source stays private.

Validation limits: Windows checks for 0.12.0 include 146 frontend tests, 28 routine native tests (5 explicitly ignored), compilation and formatting. Real API accounts, recording hardware, fresh-machine installation and upgrades, and long-term use still need human validation.
