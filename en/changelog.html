Changelog

Client versions and website distribution are tracked separately. Public distribution copies existing installers byte for byte; the website launch does not rebuild them.

01

0.16.1 · Contributor profile links

Fix opening contributor GitHub profiles, keep icon buttons and display names, and add pppp. Includes the earlier 0.16.0 branch merge workflow, full-window mind-map canvas and matching offline HTML exports.

02

0.15.0 · Save, find and export

Model-organized drafts save automatically with history. Full-text search opens matching messages, annotations and notes. Per-conversation storage reduces duplicated text. Choose a sharing or personal export scope before exporting.

03

0.14.0 · A quieter start & focused notebooks

Installer-only downloads, quieter About and start screens, an empty notebook before any answers, no browser context menu, and Simplified Chinese for fresh workspaces.

04

0.13.0 · Signed automatic updates

Background checks and downloads, install now or on the next launch, and a manual check in About. Source is available under PolyForm Perimeter 1.0.1.

05

0.12.0 · Previous stable release

Sending no longer forces context preview; deliberate selections remain saved. Fixes startup language flashes and adds a three-language privacy policy, a 24-hour recycle bin, a laboratory placeholder and a participation page.

06

0.11.0 · Rollback

Improves reading markers during scrolling, pasted-image previews and context-window layout. Moves voice settings to Models & connection and fixes repeated spring expansion in mind maps.

07

Website launch · 2026-10-13

An independent public website, three-language guides, a synthetic interface walkthrough and interactive mind map. This historical launch used a separate public release repository; application source became public with 0.13.0.

08

Website visual redesign · 2026-10-13

A scroll-driven forest and winding thread, the original motto, three focused features, and separate detail pages. The walkthrough video is removed. Client version and download assets remain unchanged.

See application repository docs/V0.16.1_VALIDATION.md for automated checks, signing and assistant desktop verification in an isolated workspace. Real model accounts, personal-workspace upgrades and low-end devices still require user acceptance.
