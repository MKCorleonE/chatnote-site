CHATNOTE / GUIDE

Start with your first question.

Prepare a working model API account, then try a topic without sensitive information.

01

Download and install

Choose the installer and verify its source and SHA-256. If WebView2 is missing, install it from Microsoft. Preserve your existing workspace; do not overwrite it with example data.

02

Connect your model

Go to Settings → Models & connection. Add a provider, API endpoint, key and model. Keys are stored in the system vault. Connection checks do not automatically send inference requests; use the provider's official usage page when quota is unavailable.

03

Ask in the main conversation

Enter a learning topic and send. By default the main thread includes its own history, without follow-ups. Actual context remains subject to the context budget and provider limits.

04

Select a passage and ask more

Select text or an equation to create a branch. By default it uses the snapshot through the source answer and that branch's history, without sibling branches, later main-thread turns or private notes.

05

Select context when needed

Open Preview context to choose the scope. Main conversations and follow-ups remember selections separately; new history is not automatically added to a saved selection. Restore defaults if needed and inspect the actual request beside its answer.

06

Export results and back up

Add private notes and export notes or HTML maps. Export model-organized notes before closing. Full workspace backups restore original conversations, unlike learning exports; they do not contain vault credentials.

A few things before you start

Is it free?

The current client is a free beta. API quotas, prices and terms are set by your model provider; the download includes no model credits.

Does every model support images, files and voice?

No. Images require a vision-capable model. Uploading a file does not mean the model can read it; direct raw-document use with DeepSeek is not guaranteed. Voice requires a transcription-capable API connection in Models & connection. Arbitrary chat APIs are not guaranteed to support transcription.

What is the context budget?

It limits the scale of historical text in a request by characters, not your provider balance or an exact token quota. History may be shortened or omitted above this limit; inspect the actual request receipt.

Can I restore deleted conversations?

Whole conversations remain in the recycle bin for 24 hours and are cleared on the next launch after expiry. Restore them before cleanup, or confirm immediate deletion. Individual answer deletion does not use the conversation recycle bin.

Does my content leave my device?

Local storage does not make model requests offline. Sending transmits your selected context, applicable attachments or transcription audio to the configured service. Check that service's data policy.

Can I use a ChatGPT subscription or another platform?

The initial public beta guide focuses on your own API access. It makes no promise about ChatGPT subscription authorization or third-party distribution. Only Windows x64 is currently delivered.

What if downloading is slow or fails?

Downloads are hosted on GitHub Releases and depend on your network. Retry from the release page, then verify the full file. Report your OS, network type and error time without sending keys or private chats.
