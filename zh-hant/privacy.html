隱私政策

生效日期：2026-10-13。本說明分別描述官網訪問和 ChatNote 客戶端。這裡只按當前實現說明資料流，不承諾尚未實現的加密、同步或第三方刪除能力。

01

官網訪問與託管

官網由 GitHub Pages 託管，安裝包由 GitHub Releases 分發。GitHub 為安全目的會記錄訪客 IP 地址，即使未登錄。本站未接入額外的第三方統計、廣告或追蹤腳本；GitHub 的日誌、保留與處理遵循其隱私政策。

02

官網本機偏好

語言通過不同頁面地址切換。導覽進度僅保留在當前頁面內，不建立使用者賬號、不收集聊天或 API 密鑰。複製按鈕訪問剪貼板僅用於寫入使用者點擊選擇的公開文字。

03

客戶端本機保存

對話、版本、批註錨點、筆記、草稿、閱讀位置與偏好保存在本機工作區；附件也會在本機保存。當前不提供開發者託管的雲同步，工作區資料庫不承諾本機全盤加密。請自行保護設備和備份。

04

憑據與模型請求

API 密鑰和登錄憑據存入系統憑據庫。發送時，你選擇的上下文和適用附件會傳到配置的模型服務；語音轉寫會把錄音傳到所選轉寫服務。私人筆記不會自動進入模型請求。

05

第三方連接

模型、轉寫、認證、服務商用量頁面與下載託管均屬於第三方服務，可能處理請求內容、賬號及網絡信息。適用其各自政策和使用條件，ChatNote 無法替第三方承諾不留存或刪除。

06

保留、回收站與刪除

整個對話刪除後保留 24 小時，在超時後下一次啟動清理。可在清理前恢復，也可確認後立即永久刪除。永久清理同時處理對應恢復記錄與未共享附件；不承諾磁盤級安全擦除，已匯出檔案或第三方副本需另行管理。

07

匯出、備份與反饋

備份與匯出檔案由你管理，可能包含私人內容，但不包含系統憑據庫中的密鑰。聯繫開發者時，你主動發送的郵箱、描述和螢幕截圖將用於溝通與處理反饋；請不要提交密鑰或敏感原文，需要刪除已發反饋時可聯繫開發者。

08

選擇與聯繫

你可選擇模型、預覽發送範圍、停止請求、管理回收站與備份；第三方已接收的內容不會因本機停止而撤回。隱私問題請聯繫 529023573@qq.com 或小紅書號 1006863642。本說明更新會註明日期。
