常見問題

可以免費使用嗎？

當前客戶端免費提供測試使用。模型 API 的額度、計費與使用條件由你選擇的服務商決定；下載客戶端不附贈模型額度。

每個模型都支持圖片、檔案和語音嗎？

不一定。圖片取決於所選模型的視覺能力；檔案上傳成功不代表模型能閱讀檔案，DeepSeek 原始文檔附件尚不能保證直接使用。語音需在模型與連接中選擇支持轉寫的 API 連接；不承諾任意聊天 API 都支持語音。

上下文預算是什麼？

它限制本次請求可以攜帶的歷史字符規模，不是服務商餘額，也不是精確 token 額度。超出預算時會縮略或省略部分歷史；可查看實際請求收據。

刪除後能恢復嗎？

整個對話進入回收站後保留 24 小時。超時後在下次啟動時清理；清理前可恢復，也可確認後立即刪除。單條回答刪除不進入對話回收站。

我的內容會被上傳嗎？

本機保存不代表請求完全離線。發送問題時，所選上下文、附件或轉寫音頻會傳到你配置的服務。第三方的資料處理規則請查看其政策。

能用 ChatGPT 套餐或在其他平臺安裝嗎？

首期公開試用指南以自備 API 為主，不承諾 ChatGPT 套餐授權與第三方分發的可用性。當前只提供 Windows x64，其他平臺尚未交付。

下載慢或者失敗怎麼辦？

下載由 GitHub Releases 提供，速度取決於網絡。可打開發布頁重試，校驗完整檔案後再運行。請反饋系統、網絡類型和錯誤時間，不發送密鑰或私人聊天。
