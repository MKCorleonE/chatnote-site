CHATNOTE / GUIDE

從第一個問題開始。

準備一個可用的模型 API 賬號，再用一段不含敏感信息的內容開始體驗。

01

下載與安裝

選擇安裝版，確認來源與 SHA-256。缺少 WebView2 時從微軟官方頁面安裝運行時；保留已有工作區，不用示例數據覆蓋自己的內容。

02

連接你的模型

進入設置 → 模型與連接，添加服務商、API 地址、密鑰與模型。密鑰保存在系統憑據庫。連接檢查不會自動發送推理請求；餘額不可用時請到服務商官方用量頁面查看。

03

提出主線問題

輸入一個學習主題併發送。主線默認攜帶當前主線歷史，不包含追問；實際發送範圍仍受上下文預算與服務商限制影響。

04

選中原文，繼續追問

選中回答中的文字或公式，建立旁支。追問默認使用截至來源回答的快照與本條追問歷史，不帶兄弟追問、後續主線或私人筆記。

05

需要時選擇上下文

主動點擊“預覽上下文”選擇本次範圍。主線與追問分別記住選擇；新歷史不會自動加入已選範圍。可恢復默認，再在回答旁查看實際請求內容。

06

導出成果，備份工作區

寫私人筆記並導出筆記或導圖 HTML。模型整理出來的筆記需在關閉前導出。完整工作區備份用於恢復原會話，不等同於學習成果導出；備份不含系統密鑰。

開始前，可能想知道

可以免費使用嗎？

當前客戶端免費提供測試使用。模型 API 的額度、計費與使用條件由你選擇的服務商決定；下載客戶端不附贈模型額度。

每個模型都支持圖片、文件和語音嗎？

不一定。圖片取決於所選模型的視覺能力；文件上傳成功不代表模型能閱讀文件，DeepSeek 原始文檔附件尚不能保證直接使用。語音需在模型與連接中選擇支持轉寫的 API 連接；不承諾任意聊天 API 都支持語音。

上下文預算是什麼？

它限制本次請求可以攜帶的歷史字符規模，不是服務商餘額，也不是精確 token 額度。超出預算時會縮略或省略部分歷史；可查看實際請求收據。

刪除後能恢復嗎？

整個對話進入回收站後保留 24 小時。超時後在下次啟動時清理；清理前可恢復，也可確認後立即刪除。單條回答刪除不進入對話回收站。

我的內容會被上傳嗎？

本機保存不代表請求完全離線。發送問題時，所選上下文、附件或轉寫音頻會傳到你配置的服務。第三方的數據處理規則請查看其政策。

能用 ChatGPT 套餐或在其他平臺安裝嗎？

首期公開試用指南以自備 API 為主，不承諾 ChatGPT 套餐授權與第三方分發的可用性。當前只提供 Windows x64，其他平臺尚未交付。

下載慢或者失敗怎麼辦？

下載由 GitHub Releases 提供，速度取決於網絡。可打開發布頁重試，校驗完整文件後再運行。請反饋系統、網絡類型和錯誤時間，不發送密鑰或私人聊天。
