ChatNote / GUIDE

從第一個問題開始。

準備一個可用的模型 API 賬號，再用一段不含敏感信息的內容開始體驗。

01

下載與安裝

選擇安裝版，確認來源與 SHA-256。缺少 WebView2 時從微軟官方頁面安裝運行時；保留已有工作區，不用示例資料覆蓋自己的內容。

02

連接你的模型

進入設置 → 模型與連接，添加服務商、API 地址、密鑰與模型。密鑰保存在系統憑據庫。連接檢查不會自動發送推理請求；餘額不可用時請到服務商官方用量頁面查看。

03

提出主線問題

輸入一個學習主題併發送。主線預設攜帶當前主線歷史，不包含追問；實際發送範圍仍受上下文預算與服務商限制影響。

04

選中原文，繼續追問

選中回答中的文字或公式，建立旁支。追問預設使用截至來源回答的快照與本條追問歷史，不帶兄弟追問、後續主線或私人筆記。

05

需要時選擇上下文

主動點擊“預覽上下文”選擇本次範圍。主線與追問分別記住選擇；新歷史不會自動加入已選範圍。可恢復預設，再在回答旁查看實際請求內容。

06

匯出成果，備份工作區

寫私人筆記並匯出筆記或導圖 HTML。模型整理出來的筆記需在關閉前匯出。完整工作區備份用於恢復原會話，不等同於學習成果匯出；備份不含系統密鑰。
