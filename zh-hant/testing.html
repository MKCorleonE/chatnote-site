ChatNote / TESTING

一起完成一次學習

首期希望收集約 10–20 位 Windows 使用者的體驗。這裡只提供自願試用與聯繫說明，不會自動邀請或發送信息。

  1. 記錄 Windows 版本、網絡類型、客戶端版本；確認下載檔案校驗一致。
  2. 在新電腦或已備份的工作區安裝；檢查啟動與原資料保留。
  3. 配置自己的可用 API，用不含敏感信息的內容完成主線提問和原文追問。
  4. 主動選擇上下文，檢查繼續發送、切換與重啟後範圍是否保留。
  5. 匯出筆記與導圖 HTML，再重啟查看對話與筆記是否保留。
  6. 在 Wi-Fi 和移動網絡分別查看官網、下載；記錄失敗時間與提示。

反饋格式

版本 / Windows 版本 / 網絡類型 / 復現步驟 / 預期結果 / 實際結果 / 已脫敏螢幕截圖。不要發送 API 密鑰、完整私人工作區或真實敏感資料。

此清單需試用者實際完成。自動測試與合成演示不能替代真實賬號、設備和地區網絡的驗收。
