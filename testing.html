一起完成一次学习

首期希望收集约 10–20 位 Windows 用户的体验。这里只提供自愿试用与联系说明，不会自动邀请或发送信息。

  1. 记录 Windows 版本、网络类型、客户端版本；确认下载文件校验一致。
  2. 在新电脑或已备份的工作区安装；检查启动与原数据保留。
  3. 配置自己的可用 API，用不含敏感信息的内容完成主线提问和原文追问。
  4. 主动选择上下文，检查继续发送、切换与重启后范围是否保留。
  5. 导出笔记与导图 HTML，再重启查看对话与笔记是否保留。
  6. 在 Wi-Fi 和移动网络分别查看官网、下载；记录失败时间与提示。

反馈格式

版本 / Windows 版本 / 网络类型 / 复现步骤 / 预期结果 / 实际结果 / 已脱敏截图。不要发送 API 密钥、完整私人工作区或真实敏感资料。
