ChatNote / PRIVACY

隐私政策

生效日期：2026-10-19。本说明分别描述官网访问和 ChatNote 客户端。这里只按当前实现说明数据流，不承诺尚未实现的加密、同步或第三方删除能力。

01

官网访问与托管

官网由 GitHub Pages 托管，安装包由 GitHub Releases 分发。GitHub 为安全目的会记录访客 IP 地址，即使未登录；其日志、保留与处理遵循 GitHub 隐私政策。软件会检查公开版本文件并从 GitHub 下载签名更新。托管服务接收 IP 地址等常规网络信息，不附带聊天、笔记或凭据。

02

官网访问统计

官网使用 Cloudflare Web Analytics 了解浏览量、访问来源、设备类别及页面性能，统计由开发者在登录后台后查看，不在官网展示。正式官网会加载 Cloudflare 的统计脚本并将访问与性能数据发送至 Cloudflare；不使用分析 Cookie，不收集聊天、笔记、API 密钥或客户端使用记录。本地预览不启用统计；本网站也尊重浏览器的“请勿追踪”和 Global Privacy Control 信号。网络限制或拦截工具可能造成漏计。安装包下载次数使用 GitHub 的公开附件计数，不代表独立用户数或安装成功数。

03

官网本机偏好

语言通过不同页面地址切换。界面示意中的选择仅保留在当前页面内，不建立用户账号、不收集聊天或 API 密钥。复制按钮访问剪贴板仅用于写入用户点击选择的公开文字。

04

客户端本机保存

对话、版本、批注锚点、笔记、草稿、阅读位置与偏好保存在本机工作区；附件也会在本机保存。当前不提供开发者托管的云同步，工作区数据库不承诺本机全盘加密。请自行保护设备和备份。 0.15.0转换数据库前会在数据库旁保留chatnote.pre-v015.sqlite升级前备份；该独立备份可能含旧记录，不会随回收站清理改写，请自行管理。

05

凭据与模型请求

API 密钥和登录凭据存入系统凭据库。发送时，你选择的上下文和适用附件会传到配置的模型服务；语音转写会把录音传到所选转写服务。私人笔记不会自动进入模型请求。

06

第三方连接

模型、转写、认证、服务商用量页面与下载托管均属于第三方服务，可能处理请求内容、账号及网络信息。适用其各自政策和使用条件，ChatNote 无法替第三方承诺不留存或删除。

07

保留、回收站与删除

整个对话删除后保留 24 小时，在超时后下一次启动清理。可在清理前恢复，也可确认后立即永久删除。永久清理同时处理对应恢复记录与未共享附件；不承诺磁盘级安全擦除，已导出文件或第三方副本需另行管理。

08

导出、备份与反馈

备份与导出文件由你管理，可能包含私人内容，但不包含系统凭据库中的密钥。联系开发者时，你主动发送的邮箱、描述和截图将用于沟通与处理反馈；请不要提交密钥或敏感原文，需要删除已发反馈时可联系开发者。

09

选择与联系

你可选择模型、预览发送范围、停止请求、管理回收站与备份；第三方已接收的内容不会因本机停止而撤回。隐私问题请联系 529023573@qq.com 或小红书号 1006863642。本说明更新会注明日期。
